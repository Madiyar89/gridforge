# Корпоративные/государственные CA-сертификаты

Если твоя сеть перехватывает TLS (корпоративный прокси, гос. шлюз и
т.п.) — `apt`/`pip` при сборке образа не смогут достучаться до внешних
зеркал без доверенного сертификата этого перехватчика.

Положи сюда `.crt`-файл(ы) своего root CA (экспортируй из хранилища
сертификатов ОС/браузера) — `Dockerfile` подхватит их автоматически
через `update-ca-certificates` при сборке. Файлы в этой папке в
`.gitignore` — случайно закоммитить сертификат конкретной сети не
получится.

Если твоя сеть не перехватывает TLS — просто оставь папку пустой,
ничего дополнительно настраивать не нужно.
