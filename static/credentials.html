Учётки

Централизованный логин/пароль для подключения к узлам — вместо ввода при каждом бэкапе/консоли/Рубке/Сценарии/действии с портом. Область — конкретный узел (приоритет выше), группа, или «по умолчанию» (если для узла/группы своей нет — для зоопарка разного оборудования можно завести учётку на каждый коммутатор отдельно). Пароль хранится зашифрованным и после сохранения не показывается — только факт, что он задан.
