MikroTik (RouterOS)

ЗадачаКоманда
Версия / модель/system resource print
Текущий конфиг/export
Статус интерфейсов/interface print
MAC-таблица (на bridge)/interface bridge host print
ARP/ip arp print
VLAN на bridge-порту/interface bridge vlan add bridge=bridge1 tagged=ether1 vlan-ids=100
Транк (несколько VLAN, тегированный порт)/interface bridge vlan add bridge=bridge1 tagged=ether1 vlan-ids=10,20,30 (тот же tagged=, просто несколько vlan-ids через запятую)
LACP / агрегация (bonding)/interface bonding add slaves=ether1,ether2 mode=802.3ad name=bond1
STP — статус / настройка на bridge/interface bridge print; включить RSTP — /interface bridge set bridge1 protocol-mode=rstp
STP — root guard, edge-port, BPDU guard на порту/interface bridge port set [find interface=ether1] restricted-role=yes / edge=yes / bpdu-guard=yes
Диагностика интерфейса (ошибки/счётчики)/interface ethernet print stats / /interface monitor-traffic ether1
DHCP snooping (доверенный порт)/interface bridge set bridge1 dhcp-snooping=yes → /interface bridge port set [find interface=ether1] trusted=yes (на порту к легитимному DHCP-серверу)
ARP inspectionПрямого аналога (DAI) нет — ближайшее: /interface bridge set bridge1 arp=reply-only (отвечать только на статические ARP-записи, не то же самое, что проверка по DHCP snooping-таблице)
Сохранить конфиг/system backup save name=backup1 (бинарный) или /export file=backup1 (текстовый)
Перезагрузка/system reboot
Ping / traceroute/ping 8.8.8.8 / /tool traceroute 8.8.8.8
Локальный пользователь/user add name=admin group=full password=<pass>
Включить SSH, выключить Telnet/ip service set ssh disabled=no / /ip service set telnet disabled=yes
Firewall filter (аналог ACL)/ip firewall filter add chain=input src-address=192.168.250.0/24 action=accept
Port securityПрямого аналога нет — ближайшее: /interface bridge port set [find interface=ether1] learn=no (жёсткий allowlist MAC вручную, не то же самое, что sticky port-security)
SNMP (community / v3)/snmp set enabled=yes → /snmp community add name=public addresses=192.0.2.0/24; v3 — /snmp community add name=v3user security=private authentication-protocol=sha authentication-password=<pass> encryption-protocol=aes encryption-password=<pass>
AAA — RADIUS/radius add address=192.0.2.10 secret=<secret> service=login → /user aaa set use-radius=yes
AAA — TACACS+Встроенной поддержки TACACS+ нет — только RADIUS
