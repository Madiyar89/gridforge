Доменная инвентаризация

Этап 1 — nmap ping-скан подсети (живые хосты). Этап 2 — для каждого живого хоста опрос по WinRM/SMB: домен, залогиненный компьютер, ОС. Учётка подбирается автоматически по группе/диапазону.

Credential-наборы

Приоритет: точный диапазон своей группы → группа без диапазона (дефолт) → диапазон без группы (глобальный) → совсем глобальный дефолт. Fallback-метод необязателен — anonymous SMB как последний рубеж пробуется всегда сам, даже без явного fallback.

Новый скан

Ping-скан + WinRM/SMB на каждый живой хост — может занять несколько минут на большой подсети.
