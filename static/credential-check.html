Проверка доступа

Проверка SMB-учётки на узлах группы — только «этот логин/пароль работает здесь или нет», без выполнения команд и без извлечения секретов. Учётка нигде не сохраняется, вводится заново при каждом запуске.

Запускайте только на сетях, на тестирование которых у вас есть разрешение. Неавторизованная проверка учётных данных на чужой инфраструктуре может быть незаконной.
