# Страница: Потоки трафика (`static/flows.html`)

## Назначение

Анализ сетевых потоков (NetFlow/sFlow-подобные данные) — топ по
хостам, парам хостов, протоколам, плюс правила алертинга по потокам.

## Данные / API

- `GET /api/flows/top-talkers` — топ хостов по объёму
- `GET /api/flows/top-pairs` — топ пар хост—хост
- `GET /api/flows/top-protocols` — топ протоколов
- `GET /api/flows` — сырые записи потоков
- `GET/POST/DELETE /api/flow-alert-rules` — CRUD правил алертинга по
  потокам

## Что на странице (UI)

- Панели топ-N по хостам/парам/протоколам
- Список/CRUD правил алертинга

## Известные пробелы (по коду, не оценочно)

- Источник данных потоков (собственный сборщик, sFlow-агент на
  устройствах и т.п.) не устанавливался в этом разборе — требует
  чтения движка сбора отдельно.
- Не проверено пересечение с `graph-dashboards` (001) — потоки могли
  бы быть ещё одним типом панели дашборда, сейчас не входят в
  зафиксированный в 001 список widget-типов (`line`/`area`/`stat`/
  `incidents`/`syslog`).
