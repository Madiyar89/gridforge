# Страница: Рубка (`static/rubka.html`)

## Назначение

Выполнение одной read-only команды сразу на наборе узлов ("рубка" —
разовый массовый прогон), собственная реализация GridForge того же
паттерна, что "очередь на Ansible" в NetOpsHub, но через `asyncssh`
напрямую, без отдельного Ansible-раннера. Только заранее одобренные
команды (whitelist), учётные данные запрашиваются на момент запуска и
не сохраняются — тот же принцип, что у бэкапов и SSH-консоли.

## Данные / API

- `GET /api/sweep-presets` — список разрешённых (whitelisted) команд
- `GET/POST /api/sweeps` — запуск прогона / список прошлых, с `limit`
- `GET /api/sweeps/{id}` — результат конкретного прогона по узлам

## Что на странице (UI)

- Выбор команды из пресетов, выбор узлов/группы
- Ввод учётных данных для разового прогона
- Список прошлых прогонов и их результаты

## Известные пробелы (по коду, не оценочно)

- Whitelist команд (`sweep_commands`) хранится в коде/БД — не
  проверялось, можно ли его расширять через UI или только через код
  (если только через код — это осознанное ограничение, не пробел).
