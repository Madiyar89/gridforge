# Страница: Спроси про сеть (`static/ask.html`)

## Назначение

Вопрос на естественном языке о состоянии сети, отвечает ИИ (Gemini,
через интеграцию — см. `integrations.md`), read-only доступ к схеме БД.

## Данные / API

- `POST /api/ask {"question": "..."}` — единственный эндпоинт
  (`app/ask_engine.py:ask_network`)

## Что на странице (UI)

- Поле вопроса, ответ ИИ

## Известные пробелы (по коду, не оценочно)

- **На MySQL честно отказывает** (см. `docs/specs/000-platform-foundations.md`
  и коммит перехода на MySQL, 2026-09-30) — `_schema_summary()`
  безусловно открывает `DB_PATH` как SQLite-файл; на MySQL нет
  read-only СУБД-учётки, которую GridForge сам заводит. Это
  задокументированный, принятый пробел, не забытый баг.
- Зависит от интеграции `gemini` (ключ/модель) — без неё страница
  бесполезна, см. `integrations.md`
