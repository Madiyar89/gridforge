# Страница: SSH-консоль (`static/console.html`)

## Назначение

Полноценный терминал в браузере (xterm.js) с WebSocket-мостом до
`app/console_ws.py` — интерактивная SSH-сессия на узел прямо из
GridForge, оформлена под классический зелёный-на-чёрном терминал
(по прямому запросу пользователя, 2026-09-24).

## Данные / API

- WebSocket-соединение к `app/console_ws.py` (не обычный REST `api()`
  вызов)

## Что на странице (UI)

- Терминал xterm.js, ввод команд, вывод в реальном времени

## Известные пробелы (по коду, не оценочно)

- Как и `rubka.html`/backup-механизм — учётные данные для SSH-сессии,
  судя по общему принципу проекта, запрашиваются на месте и не
  хранятся; сам факт этого именно для `console_ws.py` не
  перепроверялся построчно в этом разборе.
- Не проверено логирование/аудит команд, введённых через эту
  интерактивную консоль (в отличие от `rubka`, где выполняются только
  заранее одобренные read-only команды).
