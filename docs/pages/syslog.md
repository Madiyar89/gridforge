# Страница: Syslog (`static/syslog.html`)

## Назначение

Просмотр принятых syslog-сообщений (свой UDP-приёмник, порт 5140 — не
514, чтобы не требовать root) + отдельная утилита поиска
"IP/текст → hostname/пользователь" (не связана с самими логами
напрямую, отдельная панель на той же странице).

## Данные / API

- `GET /api/nodes` — для фильтра по узлу
- `GET /api/syslog?node_id=...` — сами сообщения, `limit` по умолчанию
  100, максимум 500 (`app/main.py:3457`) — **фильтр по тексту
  сообщения сейчас отсутствует**, только `node_id`/`source_ip`/`limit`
- `GET /api/geoip-lookup?ip=...` — гео-данные по IP (для панели
  "Поиск IP → hostname/пользователь", не для самих сообщений)
- `GET /api/ip-lookup?q=...` — тот же поиск, по IP или тексту

## Что на странице (UI)

- Панель "Поиск IP → hostname/пользователь" — отдельная утилита,
  не про содержимое логов
- Фильтр по узлу (`#syslog-node-filter`)
- Лента сообщений: severity-иконка, время, источник (+ гео, если не
  приватный адрес), текст сообщения

## Известные пробелы (по коду, не оценочно)

- Нет полнотекстового поиска по тексту сообщения — **уже закрывается
  002** (FTS5/FULLTEXT, параметр `q`, экранирование, подсветка
  совпадения на фронте)
- Нет time-range фильтра (`since`/`until`) — только последние `limit`
  сообщений; не в 002 (явно out of scope там), отдельный вопрос
- Панель "Поиск IP → hostname/пользователь" логически не про syslog —
  на одной странице с логами исторически, не по архитектурной причине
