# Страница: Поиск по MAC (`static/mac-search.html`)

## Назначение

Поиск, за каким портом/узлом сети сейчас числится конкретный
MAC-адрес — по последним собранным MAC-таблицам.

## Данные / API

- `POST /api/reports/mac-search?q=...` — единственный эндпоинт

## Что на странице (UI)

- Поле поиска по MAC, результат (узел + порт)

## Известные пробелы (по коду, не оценочно)

- Не проверялось, ищет по живым данным (как `hubs.html`) или по
  последним сохранённым MAC-таблицам — судя по `GET`/`POST`-паттерну
  других похожих отчётов (`compliance`, `probable-hubs`), вероятно
  разные модели свежести данных на разных отчётных страницах, но это
  не перепроверено построчно для именно этой страницы.
