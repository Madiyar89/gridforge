# Страница: Проверка учётных данных (`static/credential-check.html`)

## Назначение

Массовая проверка, что сохранённые учётные данные (`Credential`) всё
ещё подходят к узлам — по группе или по VLAN, с выбором конкретных
целей.

## Данные / API

- `GET/POST /api/groups/{id}/credential-checks` — запуск/история
  проверок по группе
- `GET /api/vlans` — выбор VLAN как альтернативного среза целей
- `GET /api/credential-checks/{id}/targets` — конкретные узлы конкретного
  прогона и их результат

## Что на странице (UI)

- Выбор группы/VLAN
- Запуск проверки, история прогонов
- Детализация по целям конкретного прогона

## Известные пробелы (по коду, не оценочно)

- Не проверялось, ротируются/помечаются ли автоматически "битые"
  Credential после неудачной проверки, или это чисто информационная
  страница без последствий для `Credential`.
