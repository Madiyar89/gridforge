# Страница: Вход (`static/login.html`)

## Назначение

Страница аутентификации — единственная страница проекта, работающая
до получения ключа доступа.

## Данные / API

- `GET /api/oidc-status` — узнать, включён ли SSO/OIDC вход
- `POST /api/login` — обычный логин/пароль

Оба вызова идут через "голый" `fetch()`, а не через общий `api()`
хелпер из `common.js` — сделано намеренно, поскольку `api()`
предполагает уже имеющийся ключ доступа для авторизации запроса, а до
входа его ещё нет.

## Что на странице (UI)

- Форма логин/пароль
- Кнопка SSO-входа, если `oidc-status` говорит, что он включён

## Известные пробелы (по коду, не оценочно)

- Не проверялось поведение при одновременно включённых
  логин/пароль и OIDC (приоритет одного над другим, что показывается
  пользователю).
