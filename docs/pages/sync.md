# Страница: Синхронизация сайтов (`static/sync.html`)

## Назначение

Настройка синхронизации между площадками/инстансами GridForge
("sites") — точное назначение (репликация инвентаря? конфигов?
whole-DB?) не выяснено в этом разборе.

## Данные / API

- `GET/POST/PUT/DELETE /api/sync/sites` — CRUD

## Что на странице (UI)

- Список площадок синхронизации, добавление/редактирование/удаление

## Известные пробелы (по коду, не оценочно)

- Что именно синхронизируется между `sites` (инвентарь, конфиги,
  правила) не установлено — единственный найденный эндпоинт (`CRUD
  sites`) описывает только регистрацию площадок, не сам процесс
  синхронизации; требует отдельного чтения движка синхронизации перед
  тем, как опираться на эту страницу в новых задачах.
