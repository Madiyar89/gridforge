# Страница: Вероятные хабы (`static/hubs.html`)

## Назначение

Живой опрос MAC-таблиц и CDP по узлам для обнаружения "вероятных
хабов" — портов, где видно много MAC-адресов сразу (признак
неуправляемого коммутатора/хаба или неверно классифицированного
устройства), а не заранее посчитанный отчёт.

## Данные / API

- `POST /api/reports/probable-hubs?group_id=...` — единственный
  эндпоинт, делает живой опрос на момент запроса (не читает
  закешированные данные)

## Что на странице (UI)

- Выбор группы, кнопка запуска, список подозрительных портов/узлов

## Известные пробелы (по коду, не оценочно)

- Живой опрос при каждом запросе — на больших группах потенциально
  медленный/нагружающий узлы вызов; таймауты/ограничение размера
  группы не проверялись в этом разборе.
