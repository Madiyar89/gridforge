# Страница: Интеграции (`static/integrations.html`)

## Назначение

Хранение доступа к внешним системам (Graylog, Zabbix, MaxMind
GeoLite2, Gemini) — URL + токен, с кнопкой проверки соединения. Своя
версия аналогичной страницы из NetOpsHub, добавлена по прямому запросу
пользователя (2026-09-21: "надо добавить интеграцию в учётки что бы я
мог добавлять graylog and zabbix").

## Данные / API

- `GET /api/integrations` — список настроенных интеграций (по ключам
  из `INTEGRATION_REGISTRY`)
- `PUT /api/integrations/{key}` — сохранить URL/токен для интеграции
- `DELETE /api/integrations/{key}` — удалить
- Проверка соединения выполняется через `app/integrations_engine.py`
  (`_test_graylog`, `_test_zabbix`, `_test_maxmind`, `_test_gemini`) —
  каждая функция специфична под конкретный API целевой системы

## Что на странице (UI)

- Карточка на каждый ключ из `INTEGRATION_REGISTRY`
  (graylog/zabbix/maxmind/gemini): поле URL, поле токена, кнопка
  "проверить соединение"

## Известные пробелы (по коду, не оценочно)

- **Важно для `docs/specs/001-dashboard-graphs.md`**: `Integration`
  (модель) + `INTEGRATION_REGISTRY` уже хранят URL и Fernet-шифрованный
  токен (`secrets_crypto.py`, тот же механизм, что и `Credential.password`)
  и умеют реально проверять соединение с Graylog
  (`GET {url}/api/system`, Basic Auth, токен как пароль) — но **никто
  в коде фактически не читает данные из Graylog через эту интеграцию**:
  `grep -rln "graylog" app/*.py` вне `integrations_engine.py` даёт
  только `models.py` (сама модель). То есть "проводка" (хранение +
  тест) готова, а потребителя данных (панель/отчёт, который реально
  запрашивает логи у Graylog) пока нет нигде в проекте.
  001 отложил Graylog-панель дашборда как "не сейчас, просто пример
  гибкости" — технически это решение остаётся верным (никто пока не
  читает данные), но если/когда до этого дойдёт, часть работы
  (хранение URL/токена, проверка связи) уже сделана здесь.
- Аналогично: `zabbix` тоже только хранится+тестируется, не
  используется ни для одного отчёта/панели в текущем коде.
- `maxmind`/`gemini` — `gemini` реально используется на `ask.html`
  (`app/ask_engine.py`); использование `maxmind` (GeoIP/ASN) в других
  местах кода не проверялось в этом разборе.
