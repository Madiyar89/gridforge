# Страница: Порты (`static/ports.html`)

## Назначение

Просмотр и управление портами конкретного узла, включая настройки
защиты порта (port security/защита от неавторизованных подключений).

## Данные / API

- `GET /api/nodes/{id}/ports` — список портов узла (тот же эндпоинт,
  что использует `cables.html` для выбора концов кабеля)
- `GET/POST /api/nodes/{id}/protection` — настройки защиты портов узла

## Что на странице (UI)

- Выбор узла, таблица портов
- Панель настроек защиты портов

## Известные пробелы (по коду, не оценочно)

- Общий эндпоинт `/api/nodes/{id}/ports` используется минимум двумя
  страницами (`ports.html`, `cables.html`) — при правках эндпоинта
  проверять оба места (см. также замечание в `cables.md`).
