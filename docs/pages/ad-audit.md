# Страница: Аудит Active Directory (`static/ad-audit.html`)

## Назначение

Прогон и просмотр находок аудита AD — отдельно от сетевого аудита
(`audit.html`/`network-audit.html`), другая предметная область (домен,
не сетевые устройства).

## Данные / API

- `GET /api/ad-audit/report` — сводный отчёт
- `GET /api/ad-audit/runs` — история прогонов
- `GET /api/ad-audit/runs/{id}/findings` — находки конкретного прогона
- `POST /api/ad-audit` — запустить новый прогон

## Что на странице (UI)

- Сводный отчёт
- Список прогонов, по клику — находки конкретного прогона
