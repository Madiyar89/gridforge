# Страница: Кабельные схемы (`static/cables.html`)

## Назначение

Ручное и автоматическое (discover-trunks) построение схемы физических
кабельных связей между узлами по портам, плюс печатные кабельные
ведомости по группам.

## Данные / API

- `GET /api/nodes/{id}/ports` — порты узла (для выбора концов кабеля)
- `GET/POST/DELETE /api/groups/{id}/cable-links` — CRUD связей в группе
- `POST /api/groups/{id}/cable-links/discover-trunks` — автообнаружение
  магистральных линков (вероятно, по CDP/LLDP-данным)
- `GET /api/groups/{id}/cable-schedules` — печатная кабельная ведомость

## Что на странице (UI)

- Выбор группы
- Схема связей (визуальная, узел—порт—узел)
- Кнопка автообнаружения магистралей
- Кабельная ведомость (для печати/экспорта)

## Известные пробелы (по коду, не оценочно)

- Не проверено, откуда именно берёт данные `discover-trunks` (CDP/LLDP
  таблицы или что-то ещё) — требует отдельного разбора
  `app/main.py`/движка при следующей итерации.
