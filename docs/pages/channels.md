# Страница: Каналы уведомлений (`static/channels.html`)

## Назначение

Настройка каналов оповещений (куда слать) и шагов эскалации (когда и
кому именно), используется системой инцидентов при срабатывании
Watch/Probe.

## Данные / API

- `GET/POST/DELETE /api/channels` — CRUD каналов оповещений
- `GET/POST/DELETE /api/escalation-steps` — CRUD шагов эскалации

## Что на странице (UI)

- Список каналов (добавление/удаление)
- Список шагов эскалации (порядок/условия отправки)

## Известные пробелы (по коду, не оценочно)

- Конкретные типы каналов (email/telegram/webhook и т.п.) не
  перечислялись в этом разборе — уточнить при следующей итерации.
