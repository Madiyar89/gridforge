# Страница: Скан сети (`static/scan.html`)

## Назначение

Полноценная страница сетевого сканирования (discovery) — разовые сканы
по CIDR, плановое повторяющееся сканирование, история и найденные
хосты. Более развёрнутая версия того же механизма, что доступен inline
на `inventory.html`.

## Данные / API

- `GET/POST /api/scans` — история сканов / запуск нового
- `GET/POST /api/discovery-schedules` — плановое сканирование
  (расписание)

## Что на странице (UI)

- Панель "Новый скан" — разовый скан по CIDR
- Панель "Плановое сканирование" — расписания discovery-сканов
- "История сканов" — прошлые прогоны
- "Найденные хосты" — результаты конкретного скана

## Известные пробелы (по коду, не оценочно)

- `POST /api/scans` используется и здесь, и на `inventory.html`
  (быстрый inline-скан) — один и тот же эндпоинт, два разных UI-входа;
  при правках эндпоинта проверять оба места (см. также `inventory.md`)
