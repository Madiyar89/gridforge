# Страница: Справочник команд (`static/commands.html`)

## Назначение

Статическая справочная таблица команд (Cisco/Junos и т.п.) — чистый
reference, без интерактивности.

## Данные / API

Нет. Страница не делает вызовов `api()` и не подключает отдельный
`commands.js` — только `common.js` (для шапки/навигации) и статичная
131-строчная таблица прямо в HTML.

## Что на странице (UI)

- Таблица команд (131 строка), только для чтения

## Известные пробелы (по коду, не оценочно)

- Полностью статична — обновление содержимого требует правки HTML
  руками, нет админки для этой таблицы.
