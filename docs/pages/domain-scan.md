# Страница: Скан домена (`static/domain-scan.html`)

## Назначение

Отдельный вид сканирования — по AD/LDAP-домену, а не по сети (в
отличие от `scan.html`), со своими наборами учётных данных для домена.

## Данные / API

- `GET/POST/DELETE /api/domain-scan/credential-sets` — CRUD наборов
  учётных данных для доменного скана
- `GET/POST /api/domain-scan` — история/запуск
- `POST /api/domain-scan/run` — явный запуск прогона
- `GET /api/domain-scan/{id}` — результат конкретного прогона

## Что на странице (UI)

- Наборы учётных данных для домена
- Запуск скана, история, результат конкретного прогона

## Известные пробелы (по коду, не оценочно)
