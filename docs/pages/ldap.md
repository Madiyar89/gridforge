# Страница: LDAP-подключения (`static/ldap.html`)

## Назначение

Хранение подключений к LDAP/AD-серверам, используется доменными
функциями (`ad-audit.html`/`domain-scan.html`) для авторизации/поиска
пользователей.

## Данные / API

- `GET/POST/PUT/DELETE /api/ldap-connections` — CRUD

## Что на странице (UI)

- Список LDAP-подключений, добавление/редактирование/удаление

## Известные пробелы (по коду, не оценочно)

- Не проверялось в этом разборе, какие именно из `ad-audit`/
  `domain-scan`/логина через OIDC/LDAP реально используют записи
  отсюда — требует чтения соответствующих движков.
