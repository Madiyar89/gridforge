# Страница: Поиск по конфигурациям (`static/config-search.html`)

## Назначение

Полнотекстовый поиск по снятым бэкапам конфигураций узлов (не по
syslog — для этого отдельная задача, см. `docs/specs/002-syslog-fulltext-search.md`,
которая пока покрывает только syslog, не конфиги).

## Данные / API

- `GET /api/reports/search?q=...` — единственный эндпоинт

## Что на странице (UI)

- Поле поиска, список совпадений (узел + фрагмент конфига)

## Известные пробелы (по коду, не оценочно)

- Механизм поиска (LIKE по тексту, FTS или иное) не проверялся в этом
  разборе — в отличие от задачи 002 (там явно проектируется FTS5/
  FULLTEXT), здесь неизвестно, что уже реализовано под капотом.
- Не проверено, ищет ли по последнему бэкапу или по всей истории
  бэкапов узла.
