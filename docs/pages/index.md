# Страница: Главный дашборд (`static/index.html`)

## Назначение

Снапшот состояния всей видимой ключу сети — счётчики, стена узлов,
открытые инциденты, сводка за сутки, лента событий. Обновляется
периодически (полный `/api/dashboard` — раз в 5 секунд, см. комментарий
в `app/main.py:962`).

## Данные / API

- `GET /api/dashboard` — всё для верхних счётчиков и раздела "Состояние
  за сутки" одним запросом (`app/dashboard_engine.py:build_dashboard`)
- `GET /api/incidents` — открытые инциденты, панель "Открытые инциденты"
- `GET /api/incidents?include_resolved=true` + `GET /api/syslog?limit=30`
  — вместе, для "Ленты событий" (склейка на клиенте, отдельного
  эндпоинта нет — осознанно, ради одного виджета)
- `GET /api/dashboard/node-wall` — плотная сетка всех узлов (легче
  полного `/api/dashboard`, дёргается отдельно)
- `GET /api/dashboard/incident-trend` — для будущей стрелки тренда (см.
  "Известные пробелы")

## Что на странице (UI)

- Строка счётчиков (`stat-strip`): critical/warning (со спарклайнами),
  "молчат" (проверки есть, данных за сутки нет), info, всего узлов
- "Все узлы" — стена узлов (`node-wall`)
- "Открытые инциденты" — сгруппировано по узлу
- "Состояние за сутки" — бэкапы/аудит/syslog одной сводной таблицей
- "Лента событий" — хронологический поток инцидентов + syslog error+

## Известные пробелы (по коду, не оценочно)

- `build_dashboard` уже считает `problem_nodes` (топ-10 проблемных
  узлов), но на UI это никак не показано — закрывается 001
- Данные для стрелки тренда (`incident-trend`) уже дёргаются
  (`index.js:235`), но никак не отрисовываются на экране — закрывается 001
- Нет ни одного графика метрики во времени на этой странице —
  закрывается 001 (`graphs.html`, отдельная страница)
- Порог "error и хуже" в "Ленте событий" (`severity > 3`) и в "Состоянии
  за сутки" захардкожен по RFC 3164 одинаково в двух местах — не баг,
  просто дублирование константы, если менять порог — искать в обоих
