# Страница: Захват трафика (`static/capture.html`)

## Назначение

Управление захватами трафика (pcap) на узлах и их анализ.

## Данные / API

- `GET/POST/DELETE /api/captures` — CRUD захватов
- `GET /api/captures/{id}/analyze?method=...` — анализ захваченного
  файла (метод анализа параметризуется)

## Что на странице (UI)

- Список захватов, запуск нового
- Результат анализа выбранным методом

## Известные пробелы (по коду, не оценочно)

- Набор допустимых `method` для `/analyze` не проверялся в этом
  разборе — требует чтения соответствующего движка отдельно.
