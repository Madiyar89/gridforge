# Страница: Учётные данные (`static/credentials.html`)

## Назначение

Хранилище учётных данных (`Credential`) для подключения к узлам —
используется бэкапами, аудитом, discovery и т.д. по всему проекту.

## Данные / API

- `GET/POST/PUT/DELETE /api/credentials` — CRUD

## Что на странице (UI)

- Список сохранённых наборов логин/пароль (или ключ), добавление/
  удаление/редактирование

## Известные пробелы (по коду, не оценочно)

- Пароль/секрет шифруется через `secrets_crypto.py` (тот же механизм,
  что у `Integration.token` и cable/console по общему паттерну
  проекта) — сама страница/эндпоинт не перепроверялись построчно на
  предмет того, отдаёт ли `GET` расшифрованный секрет обратно в
  браузер или только маскированное значение.
